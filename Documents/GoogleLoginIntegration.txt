Google Login Integration — React + TypeScript

Step 1: Create Google Cloud Project & OAuth Credentials
1. Go to Google Cloud Console. :- https://console.cloud.google.com
  1.1 Log in with your Google account.
2. Create a new project
  2.1 Click the project dropdown at the top.
  2.2 Click New Project.
  2.3 Give it a name (e.g., My React App Login) and click Create.
3. Enable Google Identity Services
  3.1 Go to APIs & Services → Library
  3.2 Search for Google Identity Services API
  3.3 Click Enable
4. Create OAuth 2.0 Client ID
  4.1 Go to APIs & Services → Credentials
  4.2 Click + CREATE CREDENTIALS → OAuth client ID
  4.3 Choose Application type → Web application
  4.4 Set a name like React App Login
  4.5 Under Authorized JavaScript origins, add: http://localhost:3000 (and your production URL later)
  4.6 Click Create
5. Copy the Client ID
  5.1 You’ll see your OAuth 2.0 Client ID.
  5.2 Save it — you’ll use it in your React app.
